Overview

Magic Mayhem is a co-op wave survival game built in Unity. Players fight increasingly difficult waves of enemies using different abilities while working together to survive each encounter.

I worked on gameplay systems including scalable wave spawning, player abilities, VFX, sound, and UI integration. The project was developed collaboratively by a four-person team using Git.

My Contributions

Wave System

Developed a scalable wave spawning system supporting progressive difficulty, varied enemy types, and encounter timing.

Player Abilities

Implemented abilities including Ice Block, Chain Lightning, Meteor Strike, and Ice Cone with cooldowns, animation timing, and gameplay effects.

Game Feel

Integrated VFX, sound, and UI feedback with gameplay systems to improve the clarity and feel of combat interactions.

Team Development

Collaborated in a four-person team using Git for branching, merging, version control, and resolving integration conflicts.
